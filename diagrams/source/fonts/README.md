# Embedded chart fonts

The Spanish and Korean SVG sources contain WOFF2 subsets derived from these SIL Open Font License fonts:

- [Carlito Bold](https://github.com/google/fonts/tree/main/ofl/carlito) for Spanish.
- [Noto Serif KR](https://github.com/google/fonts/tree/main/ofl/notoserifkr) at weight 400 for Korean.

The modified subsets are named **Appendix H Sans** and **Appendix H Serif KR** inside the fonts and SVG styles. They contain the characters used by the charts. The corresponding OFL notices are included in this directory. Font data is embedded in each SVG; displaying the charts requires no font download or system font installation.
