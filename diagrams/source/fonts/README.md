# Embedded chart fonts

The SVG sources contain WOFF2 subsets derived from these SIL Open Font License fonts:

- [Arimo](https://github.com/google/fonts/tree/main/ofl/arimo) for English chart text (compatible with Arial's metrics).
- [Tinos](https://github.com/google/fonts/tree/main/ofl/tinos) for English and Spanish page headings (compatible with Times New Roman's metrics).
- [Carlito Bold](https://github.com/google/fonts/tree/main/ofl/carlito) for Spanish chart text.
- [Noto Serif KR](https://github.com/google/fonts/tree/main/ofl/notoserifkr) at weight 400 for Korean.

The modified subsets are named **Appendix H English Sans**, **Appendix H Serif**, **Appendix H Sans**, and **Appendix H Serif KR** inside the fonts and SVG styles. They contain the characters used by the charts. The corresponding OFL notices are included in this directory. Font data is embedded in each SVG; displaying the charts requires no font download or system font installation.
